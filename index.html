Локальный режим: приложение не отправляет введённый текст на собственный сервер и не требует API-ключа. Доступность и тип голосов определяются браузером и операционной системой.

Что демонстрирует проект

Open TTS Reader — reference implementation для браузерного TTS. Он показывает, как веб-приложение работает с SpeechSynthesis, SpeechSynthesisUtterance и SpeechSynthesisVoice.

  • получение списка голосов;
  • выбор языка и голоса;
  • rate / pitch / volume;
  • очередь utterance;
  • pause / resume / cancel;
  • события start / end / boundary / error;
  • разбиение длинного текста.
