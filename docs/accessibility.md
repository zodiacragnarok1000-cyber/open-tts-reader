# Accessibility considerations

A TTS reader should complement, not replace, native accessibility features.

Recommended practices:

- keep playback controls keyboard accessible;
- provide visible focus states;
- label sliders and voice selectors;
- do not rely on color alone to communicate playback state;
- provide a clear stop/cancel action;
- keep text readable while it is being spoken;
- respect reduced-motion preferences for UI animations;
- expose status changes to assistive technologies where appropriate.

Speech synthesis is particularly useful for users who prefer auditory reading, but the original text should remain available and navigable.
