# Changelog

## 1.0.0

- Initial browser TTS reader.
- Web Speech API / SpeechSynthesis reference guide.
- Voice discovery and selection.
- Rate, pitch and volume controls.
- Pause, resume and stop.
- Long-text chunking.
- TXT, Markdown and HTML file loading.
- Copy and TXT export.
- Responsive UI and optional offline shell.

### Repository quality
- Added GitHub Actions CI for JavaScript syntax, required files, repository hygiene, manifest validation, and basic HTML structure checks.
