# Open TTS Reader

Open-source browser TTS reader and reference implementation demonstrating text-to-speech with the Web Speech API and `SpeechSynthesis`.

The project covers voice discovery, voice selection, utterance parameters, queue management, pause/resume/cancel, speech events, long-text chunking and browser TTS limitations.

See the [technical guide](docs/speech-synthesis.html) for the architecture and API details.

For neural TTS, AI voices and voice cloning, see [ERA2 Voice](https://voice.era2.ai/).
